# Evidence conventions

`native_observations.json` contains successful observations from Wolfram Language
15.0.0 on Linux, loading the pinned 574,894-byte standalone package. Entries are
transcribed, normalized records, not purported raw stdout files. Source analysis,
mathematical deductions, and native observations are distinguished in the article.

`novelty_ledger.json` identifies new items, permitted deltas to existing items, and
excluded old work. The listed prior-review texts were retrieved and their nonempty
LaTeX contents checked. Review 7 additionally had its engineering section searched.

`python_validation.json` is generated by running the included independent tests.
It is evidence for the Python boundary prototype, not for the original Wolfram
package. `patch_validation.json` distinguishes executed experiments from authored candidate
artifacts and failed service calls. The complete certificate candidates were not
natively validated, and the repository-wide test suite was not run.
