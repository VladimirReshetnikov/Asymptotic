# Motivating Mathematica Stack Exchange questions

These saved question snapshots record the two examples that motivated this
repository. Each directory contains a Markdown transcription, a PDF, and an
Internet shortcut identifying the original question. The inverse-branch
snapshot also includes its saved illustration.
